# React Clone Cards

Proyecto realizado como ejercicio de aprendizaje de **React**, donde se trabajan los conceptos básicos de la librería mediante la creación de componentes reutilizables y el uso de **props** para mostrar información dinámica.

## 📋 Descripción

La aplicación muestra una serie de tarjetas (Cards) con testimonios de diferentes personas. Cada tarjeta se genera utilizando un único componente reutilizable, al que se le envían los datos mediante **props**.

Durante el desarrollo del proyecto se han trabajado los siguientes conceptos:

- Creación de componentes en React.
- Uso de props para reutilizar componentes.
- Importación de imágenes y archivos CSS.
- Organización de la estructura del proyecto.
- Estilos mediante CSS.

## 🛠️ Tecnologías utilizadas

- React
- Vite
- JavaScript
- JSX
- CSS

## 🎯 Objetivos del ejercicio

- Comprender el funcionamiento de los componentes en React.
- Aprender a reutilizar componentes mediante props.
- Organizar un proyecto siguiendo una estructura sencilla.
- Publicar la aplicación en GitHub y desplegarla en Vercel.
